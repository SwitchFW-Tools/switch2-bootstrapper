## ❓ FAQ

**Why do I need a PC?**
Nintendo implemented a hardware-level check that requires an external payload injection upon first boot. After this one-time step, all custom firmware and homebrew can be managed directly on the console.

**My antivirus flags the installer. Is it safe?**
Yes, it is 100% safe. Because this tool interacts with the Switch 2's bootloader and bypasses security checks, Windows Defender and other antiviruses will flag it as a "false positive". You may need to add it to your exclusions or temporarily disable your AV.

**Why isn't the file hosted on GitHub?**
GitHub's automated scanners frequently flag and remove homebrew executables. We host our installers on our own secure CDN to ensure the file is always available for the community without interruptions.
